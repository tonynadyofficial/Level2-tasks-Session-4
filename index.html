Video Editing Task Tracker

This project is used to manage video editing tasks using arrays.

  • showTasks() - Display all editing tasks.
  • addTask() - Add a new editing task.
  • removeTask() - Remove a task using its index.
  • updateTask() - Change the name of a task.
  • updateVideo() - Change the video type.
  • updateStatus() - Change the task status.
